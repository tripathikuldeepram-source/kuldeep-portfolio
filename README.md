# Kuldeep Ram Tripathi — Developer Portfolio

A responsive one-page portfolio built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page content and six main sections
- `style.css` — layout, colours, and responsive design
- `script.js` — mobile menu and automatic footer year
- `assets/` — place your resume, profile photo, and project screenshots here

## Before publishing
1. Search the files for `https://github.com/`, `https://www.linkedin.com/`, and `https://leetcode.com/` and replace sample profile URLs with your own.
2. Replace `your.email@example.com` with your professional email.
3. Replace the `#` project links with real GitHub repository and live demo URLs. Remove any project that is only an idea or describe it clearly as planned/in progress.
4. Keep the skills and project details accurate to what you have actually built.

## Run locally
Open `index.html` in a browser. For a smoother workflow, open the folder in VS Code and use the Live Server extension if installed.

## Publish using GitHub Pages
1. Sign in to GitHub and create a new public repository named `kuldeep-portfolio` (or another name you prefer).
2. Upload `index.html`, `style.css`, `script.js`, `README.md`, and the `assets` folder to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait a few minutes. GitHub Pages will show your website URL on the Pages settings screen.
7. Open that URL and test every link on desktop and mobile.

If you name the repository `YOUR-USERNAME.github.io`, GitHub Pages can use that as your user-site repository. Otherwise, the project URL usually includes the repository name.

## Notes
- This starter uses Google Fonts from an external stylesheet. If you want the site to work without that external request, remove the `@import` line in `style.css`; the fallback fonts will still work.
- The contact link opens the visitor's email app using `mailto:`; it does not send messages through a backend.
